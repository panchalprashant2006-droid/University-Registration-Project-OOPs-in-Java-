# University Registration Project (Java)

A Java-based university registration application demonstrating object-oriented programming concepts.

## Overview

This project provides a console-based system for managing basic university registration operations. It demonstrates how Java classes and objects can model students, courses, and registration workflows.

## Features

- Add and manage student records
- Add and manage course records
- Register students for courses
- Demonstrate core object-oriented programming concepts
- Uses Java as the primary implementation language

## Technologies

- **Language:** Java
- **Programming approach:** Object-Oriented Programming (OOP)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or newer
- A terminal or Java IDE such as IntelliJ IDEA, Eclipse, or VS Code

### Clone the Repository

```bash
git clone https://github.com/panchalprashant2006-droid/University-Registration-Project-OOPs-in-Java-.git
cd University-Registration-Project-OOPs-in-Java-
```

### Compile and Run

From the project root, identify the main Java class and compile the source files:

```bash
javac *.java
java <MainClassName>
```

Replace `<MainClassName>` with the class containing the `main` method.

If the source files are organized in directories, compile them with:

```bash
javac -d out $(find . -name "*.java")
java -cp out <package.MainClassName>
```
